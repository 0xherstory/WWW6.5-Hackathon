# 🐘 大象家务手账 (Elephant Ledger)
**"让家务劳动不再是房间里的大象。"**

大象家务手账是一款专注于**女性隐性家务劳动价值确权**的 Web3 法律科技产品。我们通过区块链技术，将日常家务劳动转化为具备司法存证潜力的数字资产凭证，赋权每一位劳动付出者，让隐形的价值被看见、被量化、被保护。

---

## 🎯 1. 我们解决的痛点问题 (Pain Points)

长期以来，家务劳动、育儿照护和情绪劳动如同“房间里的大象”——每个人都在家庭中享受着这些劳动带来的舒适，它极其沉重且显眼，但往往被社会和经济结构视而不见。

* **拒不承认背后的经济剥削：** 这种“集体沉默”并非无意，而是因为承认价值即意味着需要支付对等的经济成本。为了维持这种免费的享用，社会往往给家务劳动冠以各种“奉献”、“神圣”、“母性”等感性词汇，本质上是通过情感绑架实现对劳动付出者的无偿剥削。这种价值剥离不仅导致付出者自我价值的贬损，更让家务劳动在异化中变成了无止境的自我消耗。
* **诉讼举证艰难与价值补偿的不对等：** 《民法典》第一千零八十八条明确规定了“家务劳动补偿制度”。但在现实司法实践中，由于家务劳动具有私密性、零碎性，缺乏可信且连续的原始证据，导致在认定具体劳动量时存在巨大障碍。这不仅使得补偿请求难以获得充分支持，也导致最终判定的补偿金额往往与真实的价值付出严重不对等。对于劳动者而言，除了经济补偿，另一个紧迫的需求是**劳动被看见**——这不仅是对补偿制度的技术支撑，更是对个人人格与劳动付出的基本尊重。

## 🔗 2. 为什么一定要上链？(Why Web3?)

普通的中心化 App 记录的数据存在易被篡改、删除或事后补录的风险。在庭审对抗中，一旦对方质疑数据的原始真实性，缺乏中立技术背书的数据其**证明力**往往会被大幅削弱。

1. **适配现代司法存证趋势：** 根据相关互联网司法审理规定，区块链存证是被明确认可的取证手段。上链能赋予每条记录唯一的时间戳和防篡改属性，实现证据的**“原生真实”**。
2. **极低成本的权益保障：** 考虑到家务劳动者可能面临的经济限制，我们特意设计了**“日结哈希+月度封装”**的双层架构。这种模式通过极低 Gas 费的 Avalanche 链，将高频确权的经济门槛降至最低，确保这套法律武器不会因为经济压力而无法被需要的人使用。
3. **绝对的数据主权：** 结合 ZK (零知识证明) 技术，劳动数据仅由用户的钱包私钥掌握。在自我确认时保持隐私，在法律确权时方可作为凭证。

## 💡 3. 如何操作与使用 (How to Use)

* **Step 1: 连接身份。** 点击“连接钱包”，通过身份密钥唤醒并授权您的数字账本。
* **Step 2: 记录劳动。** 点击底部 `+` 号记录每日具体内容。系统将基于地域参考价将其转化为直观的经济价值。
* **Step 3: 今日记录上链（日结存证）。** 睡前一键上链。这不仅是数据的加密备份，更是一场与自我的对话——见证自己的劳动，确认为自我价值。
* **Step 4: 生成月度数字凭证（数据封装）。** 为极大程度节省成本，我们采用哈希树（Merkle Tree）技术，将全月数据“折叠”成唯一的哈希根。仅需一次月度交互即可锁定全月证据链，为后续生成司法级报告提供索引。

## 🚀 4. 未来愿景与路线图 (Future Vision)

* **司法证据闭环与本土化兼容：** 我们深知法庭对证据完整性的高要求。未来，大象家务手账计划接入司法可信时间戳（TSA）或具备资质的电子签名接口。在用户需要进行法律确权时，将链上的哈希树根与真实身份关联，生成**具备司法鉴定效力的电子存证报告**，完成从数字共识到法庭采信的最后闭环。
* **解构“家庭”概念，赋能所有共居空间：** 我们未来将不再局限于传统的家庭框架。在合租、伴侣同居等任何**共居空间 (Co-living Spaces)** 内，只要发生了公共维护劳动，其价值都应当被看见与确权。我们将探索更广阔的劳动价值量化与互助网络。
